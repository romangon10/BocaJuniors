# BocaJuniors

Repositorio reservado para un proyecto web de portfolio de Román González.

## Tecnologías

Por definir cuando se implemente la primera versión. Actualmente no corresponde atribuirle HTML, JavaScript, React, Java o SQL.

## Estado actual

Pendiente de implementación. El repositorio no contiene todavía una aplicación, por lo que no hay instrucciones de ejecución, demo ni pruebas que puedan verificarse.

## Criterios para la primera versión

- Definir una función principal y sus criterios de aceptación.
- Construir una interfaz adaptable a celular y escritorio, navegable por teclado.
- Separar presentación, lógica y acceso a datos.
- Identificar claramente los datos de demostración; citar fuentes si se utiliza información real del club.
- Añadir pruebas para el comportamiento principal y comandos reproducibles de ejecución.
- Publicar una demo y documentar sus limitaciones.
